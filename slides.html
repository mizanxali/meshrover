The problem

Field robots (warehouses, farms, construction, inspection) lose their internet link all the time. When they do:

  1. They keep acting on a stale planAn unreachable cloud brain should mean stop. Most stacks freeze in an unknown state, or fall back to a local guess nobody audited.
  2. The fallback link is open to anyone nearbyLocal radio control is usually unauthenticated, so anyone in range can send "go".

Our answer: the mesh tells a robot whether it still has a path to its brain. MLS makes the local link refuse a stranger. ENS says whose commands count.

Architecture

Every mesh message is sealed with MLS; an unsealed fleet.* body is refused. No rover, and no mesh link, uses the internet.

What each partner does

picks every move

A vision model sees the rover's frame and the moves on offer (Router, temperature 0).

Verified tier, on a TEE-attested model: 0gm-1.0-35b-a3b (TeeML, in a TDX enclave). A reply 0G marks not verified is refused.

0G Storage

keeps the whole run

One JSONL file per episode: every decision with its request ID and the frame the model saw, every stop, approval and denial.

Uploaded when the episode ends, retried every 15 s while offline.

0G Chain

anchors it

EpisodeAnchor on Galileo: the episode's storage root and counts. Only the base can write it, once per episode.

The dashboard lists the anchors and replays an episode from its root.

contracts/src/EpisodeAnchor.sol

World ID

a real human approves

Before zone C: World's device flow, the card on the operator's phone over the mesh, approved in World App.

The base validates the ID token itself, then issues a 10 s single-use approval.

src/base/world.ts

ENSv2

says who's in the fleet

A subname per robot, base and operator, each with its own resolver: role, mesh key, expiry; agent-context on robots.

Checked by authorize() on the base and again on the rover.

src/base/roster.ts · src/protocol.ts

Offline Protocol

carries every message

Each rover and the base run their own mesh engine. Rover B reaches the base only through rover A; phones join over Bluetooth.

MLS-sealed end to end.

The rover's state machine

Every doubt resolves to SAFE_STOPPED. Leaving it takes a fresh decision from 0G, never a timer.

Enforced on every message
